# DSE6200 Car Dealership Project

Smart Car Dealership Inventory and Sales Analytics System using MongoDB and Flask.

## Features
- Add car records
- Edit car records
- View inventory
- Analytics dashboard
- Random data generation for testing

## Technologies Used
- Python
- Flask
- MongoDB
- HTML

## Project Files
- `app.py` - main Flask application
- `generate_data.py` - generates random car sales data
- `templates/` - HTML templates for pages

## How to Run
1. Start MongoDB
2. Run:
   ```bash
   python generate_data.py
   python app.py
